#  AI Virtual Attendance System

##  Overview
The AI Virtual Attendance System is an intelligent solution that uses face recognition technology to automatically mark attendance.

This system eliminates manual attendance processes and ensures accuracy, efficiency, and security. It is designed as a full-stack application with AI integration.


##  Features

###  Face Registration System
- Capture face images using webcam
- Store user data (Name, Roll Number)
- Save images in dataset folder

###  Face Encoding System
- Convert face images into numerical encodings
- Store encodings in a file for fast recognition

###  Face Recognition System
- Detect faces in real-time using webcam
- Match with stored encodings
- Identify students instantly

###  Attendance System
- Automatically mark attendance
- Store data in Excel file
- Save Name, Roll Number, and Timestamp

###  Duplicate Prevention
- Prevents already registered users from re-registering
- Avoids multiple attendance entries

###  Web Interface
- User-friendly frontend
- Integrated backend for processing
